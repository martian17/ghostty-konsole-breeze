# Ghostty Breeze theme (Konsole) config
I liked the Breeze theme in Konsole, but I needed to switch to Ghostty (as it supports glyph joining among other things), so I decided to rip it.  
I ripped the color codes from here:  
[https://github.com/KDE/konsole/blob/master/data/color-schemes/Breeze.colorscheme](https://github.com/KDE/konsole/blob/master/data/color-schemes/Breeze.colorscheme)  
Also, `bold-is-bright = true` was needed to ensure that the bold color stayed as-is.  
![Screenshot](./Screenshot_20260916_192102.png?raw=true "Screenshot")
You may find the fonts too small. It's my taste, so you should change it if you're having a hard time reading stuff.
